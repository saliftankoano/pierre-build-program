# Agency templates

Copy these documents into the project repository and complete them as story evidence. Do not fill blanks with guesses: label facts, preferences, assumptions, unknowns, and decisions.

| Template | Use |
| --- | --- |
| `agency-user-story.md` | Turn one user outcome into an implementation-ready visual story contract |
| `prd.md` | Product problem, users, scope, and success |
| `discovery-notes.md` | Interview evidence and unresolved questions |
| `user-journey.md` | User steps, states, and failure paths |
| `estimate.md` | Scope-based estimate with uncertainty |
| `design-critique.md` | Structured UI/UX review |
| `tool-api-evaluation.md` | Evidence-backed service comparison |
| `architecture-decision-record.md` | One consequential technical decision |
| `data-model.md` | Entities, ownership, lifecycle, and RLS intent |
| `threat-model.md` | Assets, boundaries, threats, and mitigations |
| `launch-checklist.md` | Environment and release proof |
| `handoff.md` | Client and maintainer operating guide |
| `retrospective.md` | Learning and delivery reflection |
| `incident-report.md` | Timeline, impact, containment, and prevention |
| `change-request.md` | Scope, price/time impact, and approval |
| `mentor-review.md` | Graduation rubric and review decision |
| `milestone-evidence.md` | Required PR evidence and comprehension gate |
| `tool-radar.md` | Weekly unfamiliar-tool review |
| `idea-scorecard.md` | Rank ideas by value, feasibility, risk, and learning value |
| `open-source-study.md` | Map, trace, challenge, and selectively adapt a public project |
