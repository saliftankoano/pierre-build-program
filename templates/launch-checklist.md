# Launch checklist

## Product evidence

- [ ] Acceptance criteria demonstrated on preview
- [ ] Client/mentor approval recorded
- [ ] Known limitations documented

## Quality

- [ ] `npm run check`, `npm test`, `npm run test:e2e`, and `npm run build` pass
- [ ] Keyboard, focus, contrast, screen-reader labels, and responsive states checked
- [ ] Loading, empty, validation, failure, and retry behavior checked
- [ ] Performance budget checked

## Security and data

- [ ] Cross-user authorization tests pass
- [ ] No secrets in client bundle, repository, screenshots, or logs
- [ ] Preview and production variables reviewed separately
- [ ] Migrations, RLS, storage policies, backups, privacy, and retention reviewed

## Operations

- [ ] Logs/analytics/alerts provide useful signals without sensitive data
- [ ] Rollback rehearsed
- [ ] Domain, email, webhook, and dependency ownership recorded
- [ ] Handoff, incident contact, and maintenance plan accepted
