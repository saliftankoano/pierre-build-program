# Security policy

This curriculum must never contain real credentials, confidential client data, employer code, regulated personal data, or real forensic evidence.

If you find a vulnerability in the curriculum automation, use GitHub's private vulnerability reporting for this repository. Do not open a public issue with exploit details or credentials.

The secret-leak exercise uses an unmistakably fictional value generated for the drill. Treat the exercise as if it were real: revoke, rotate, examine exposure, clean history when justified, redeploy, confirm the old value fails, and file an incident report.
