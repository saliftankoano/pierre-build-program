# Use the watchlist without chasing hype

The creator list is an idea radar. It is not the curriculum's authority. A video can help you learn a term, see a visual pattern, or discover a service. Before using the idea in client work:

1. Write the problem the tool might solve.
2. Check the publication date and versions shown.
3. Open current official documentation, pricing, security/privacy terms, and license.
4. Ask Codex to compare the tool with the project's actual constraints and one simpler option.
5. Run a small, reversible experiment with synthetic data.
6. Complete `templates/tool-radar.md`; reject the tool when its costs outweigh its value.

Create one tool-radar issue each week. “Cool demo” is not a reason to add a dependency.
